# documents/

이 폴더는 `.gitignore`로 제외됩니다 (`ai-services/report-ai/app/documents/*`).
원문 PDF는 저작권/기관 내부정보 문제로 Git에 커밋하지 않습니다 — `manifest.json`과
`templates/report_templates.json`만 커밋 대상입니다.

인덱스를 빌드하려면(`python -m app.build_index`) 아래 파일들을 이 폴더에 직접 넣어야 합니다.
