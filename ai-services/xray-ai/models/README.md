이 폴더에 학습된 가중치를 넣는다.

    final_xray_defect_best.pt

19MB이므로 git에 커밋하지 않는다.
팀 드라이브에서 받아 이 위치에 배치한다.

-> 변경 내용 (8/10)

19MB로 크지 않고, CI(CodeBuild)가 GitHub에서 소스를 새로 clone해서 빌드하기 때문에
로컬에만 두는 방식으로는 CI 빌드 이미지에 모델이 포함되지 않는다(실제로 이 문제로
xray-ai pod가 `FileNotFoundError`로 기동 실패한 적 있음). 그래서 git에 커밋해서
관리한다 — 더 이상 "팀 드라이브에서 받아 배치" 방식이 아니다.

모델을 갱신할 때는 이 파일을 새 가중치로 덮어쓰고 그대로 커밋하면 된다.
